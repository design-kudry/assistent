# Изменения

Здесь записано всё, что меняется в теме. Перед обновлением прочитайте раздел своей версии: в «Ломающих изменениях» описано, что поправить в коде приложения.

Номера версий: `1.0.1` — исправлено значение; `1.1.0` — добавлен токен или стиль; `2.0.0` — изменено или удалено то, что уже используется.

## Не выпущено

- Для Check и Inter... возвращены голубой фон и белая галочка/черта на существующих `selection/checkbox/*` и `text/on-accent`. Empty сохраняет нейтральную обводку без заливки. Обновлены Figma, CSS и описание.


### AttachmentCard и Checkbox — 2026-10-27

- Сверены обновлённые варианты Doc/Xls/png (48px): текстовые стили, рамки, кнопки XS и отступы. Сырые цвета XLS/PNG и их пиктограмм привязаны к существующим file-токенам, без изменения палитры.

### TextArea — 2026-10-26

### Tabs

## 1.0.0 — 2026-10-21

Первая версия, которую можно устанавливать как пакет. Включает всё, что было сделано с 16 по 21 октября 2026.

### Ломающие изменения

Касаются тех, кто раньше подключал стандартную тему Consta, экспорт из конструктора или копию этого репозитория до 21.10.2026.

- **Размер `s` у всех контролов — 36px вместо 32px.** Затрагивает Button, TextField, Combobox, Select, ChoiceGroup и другие контролы с `size="s"`. Проверьте плотные строки, таблицы и тулбары. Размеры `xs`, `m`, `l` не изменились.
- **`Heading/S` теперь 20/30, Bold** (было 16/24, Medium). Там, где нужен прежний вид, замените `typography.headingS` на `typography.headingXs`, а переменные `--gpn-ai-heading-s-*` на `--gpn-ai-heading-xs-*`.
- **Кнопки по умолчанию круглые**, ChoiceGroup — тоже; поля ввода — радиус 12px. Если где-то нужны прямые углы, задайте `form="brick"` явно.
- **Sidebar больше не отдельный цвет.** `--gpn-ai-background-sidebar` и `--gpn-ai-bg-sidebar` теперь равны `--gpn-ai-background-surface`. Если сайдбар отличался по цвету от карточек, теперь он совпадает — так в Figma.
- **Списки и выпадающие меню**: радиус 20px, новые фон, граница и тень.

### Добавлено

- Светлый и тёмный пресеты `presetGpnAiLight`, `presetGpnAiDark` из переменных Figma. Акцент `#008EFA`, отдельная роль Control `#426A80` / `#B3C6D5`.
- Объект `typography` со всеми 26 текстовыми стилями Figma и переменные `--gpn-ai-{категория}-{роль}-*` для каждого стиля.
- `typography.headingXs` (16/24, Medium) и `typography.captionBadge` (12/24, Semi Bold) для бейджей карточек запросов.
- Класс `DsChoiceGroup_secondary2` для варианта ChoiceGroup «Secondary 2» и токен `--gpn-ai-control-background-selected` (#DFF1FF / #173D59).
- Класс `DsPromptBadge` для бейджа карточки запроса.
- Градиенты `--gpn-ai-haze` и `--gpn-ai-haze-bottom`, фон модального окна `--gpn-ai-background-overlay`.
- Свечения `--gpn-ai-glow-home`, `-chat`, `-project` и свечение каталога `--gpn-ai-catalog-glow` с размерами.
- Тени `--gpn-ai-shadow-card`, `-popover`, `-list`.
- Токены файлов, навигации, меню, контекста, статуса success и поверхностей.
- Алиасы для всех имён WEB-переменных из Figma.
- `package.json`: установка через `npm install github:design-kudry/assistent#v1.0.0`.
- Автоматическая проверка темы в GitHub Actions на каждый pull request.

### Исправлено

- Ссылки на шрифты `.woff2` и CSS-импорты в пресетах.
- Параметры нейтральных теней: в экспорте конструктора терялись второй blur и offset.
- Удалены имена `Example` из экспортированных файлов.

### Устарело

Работают как раньше, но в новом коде используйте `--gpn-ai-background-surface`: `--gpn-ai-background-sidebar`, `--gpn-ai-bg-sidebar`, `--gpn-ai-background-raised`, `--gpn-ai-bg-raised`. Вместо `--gpn-ai-composer-border` — `--gpn-ai-border-composer`.
